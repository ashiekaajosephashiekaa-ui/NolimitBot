# NooLimit Bot

NooLimit is a Telegram entertainment bot where users complete simple
in-app tasks to earn "NL" — a virtual progression token used only
inside the bot.

## Points Policy
NL has **no monetary value**. It cannot be withdrawn, sold, traded,
or exchanged for cash, crypto, or goods.

## Advertising
Optional rewarded ads may be shown. Watching ads is always a choice
and never required.

## Content
No adult content, gambling, real-money rewards, or financial services.
